`xue_hua_webview` is a Flutter WebView package that supports Android, iOS, macOS,
Windows, Linux, and Web. Its
[`xue_hua_webview_platform_interface`](https://pub.dev/packages/xue_hua_webview_platform_interface)
package is forked from Flutter's official platform interface.

This unversioned route documents the latest `1.0.0` release.

## Platform Compatibility

| Platform | Minimum target | Engine |
| --- | --- | --- |
| Android | API 24+ | `WebView` |
| iOS | 13.0+ | `WKWebView` |
| macOS | 10.15+ | `WKWebView` |
| Windows | Windows 10 1809+ | `WebView2` |
| Linux | `webkit2gtk-4.1` | `WebKitGTK` |
| Web | None | `JS interop` |
